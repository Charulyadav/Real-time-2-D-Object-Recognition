# RUNNING THE SYSTEM

Run from the project root (so the model and database files are found):

    .\bin\Release\orSystem.exe

Required files in the project root at runtime:
    resnet18-v2-7.onnx   - ResNet18 network for the CNN classifier (Task 9)
    object_db.csv        - hand-feature training database (created by training)
    embedding_db.csv     - CNN embedding database (created by CNN training)

The window opens with all four pipeline views in one dashboard:
    top-left     Original camera feed
    top-right    Cleaned threshold
    bottom-left  Colorized region map
    bottom-right Features + predicted labels

Three trackbars at the top tune the system live:
    Thresh   - adjusts the ISODATA threshold up/down (center = no offset)
    MinArea  - minimum region size to keep
    TopN     - number of regions to detect at once

# CONTROLS

  q   quit
  s   save the current dashboard to capture_<N>.jpg
  f   print the feature vector of the current object to the terminal
  e   evaluate: record true vs predicted label (for the confusion matrix)

  n   train (hand features): label the current object, append to object_db.csv
  p   toggle hand-feature classification on/off (reloads the DB)

  N   train (CNN): label the current object, append to embedding_db.csv
  P   classify the current object with the CNN once (result is cached/shown)

  l   reload the hand-feature database from disk

NOTE: when training (n / N) or evaluating (e), the program prompts for a
label in the TERMINAL. Click the terminal, type the label, press Enter.
The video window must be focused for key presses to register.

# EXTENSIONS

1. Two from-scratch algorithms (only one required):
   - ISODATA dynamic thresholding (Task 1)
   - Morphological filtering: erosion, dilation, opening, closing (Task 2)

2. Saturation-based preprocessing: darkens highly saturated pixels in HSV
   so colored objects (e.g. yellow scissor handles) threshold as foreground.

3. Multi-object recognition: keeps the top-N regions and labels them
   simultaneously, each in a distinct color.

4. Custom single-window dashboard GUI: all four pipeline views composited
   into one window with live-tunable trackbars, replacing a cluttered
   multi-window layout and improving frame rate (one imshow per frame,
   CNN run only on demand).

   To test the GUI: run orSystem.exe, place objects on a white background,
   and use the trackbars to adjust thresholding/segmentation live. Train
   objects with 'n', then press 'p' to see real-time classification.

# NOTES

- The image database (training objects) is captured live via webcam;
  no external dataset is included.
- object_db.csv and embedding_db.csv are generated by the training mode
  and are not required to be present on first run.
- Do not open the .csv files in Excel and re-save them; Excel can reformat
  the CSV in ways that break the reader. Use a plain text editor.
- csv_util.cpp/.h and the embedding functions in embedding.cpp are adapted
  from Prof. Bruce Maxwell's provided code, with attribution.
